# Дата: 2026-03-08

## Что было сделано

Реализовал базовые UI-компоненты: Button, Input, Loader, и Logo. Для типизации использовал интерфейсы ButtonHTMLAttributes и InputHTMLAttributes для того, чтобы элементы имели стандартные атрибуты. Для гибкой настройки классов использовал clsx вместо шаблонных строк.
Узнал что в React-компоненты не имеют доступ к тегам напрямую. Для валидации инпутов и при использовании React Hook Form нужно пробрасывать ссылку к самому тегу внутри компонента. Пока не до конца понимаю всю механику работы с ref, но узнал что его нельзя передать как обычный проп и для этого используется forwardRef.

## Итог

- Button имеет 2 варианта: primary и secondary, и 2 размера.
- Input поддерживает label, текст подсказки и ошибки. Использовал хук useId для автоматической связи лейбла с инпутом
- Loader реализован в 3 размерах и наследует цвет текста родителя через currentColor.
- Logo обернут в Link для навигации на главную страницу.
