**Что было сделано:** реализация AI-чата на бэкенде (POST /ai/chat), хранение истории диалога с AI-ассистентов в бд, 
запись видео для Week 3 Checkpoint.

**AI-ассистент.** Реализовал эндпоинт POST /ai/chat: защита JWT, в теле - message и conversationId для продолжения диалога, 
в ответе — conversationId, messageId, reply. История диалогов и сообщений хранится в бд (через Prisma). Провайдер LLM 
выбирается при старте по переменной окружения: предусмотрено переключение API используемой LLM на локальную модель или AI-платформу без правок в коде.
Реализовано это через стратегию.

**Зачем история на бэкенде.** Диалоги и сообщения хранятся в бд на бэкенде - одна точка истины. Пользователь может 
залогиниться с любого браузера или с телефона и продолжить ту же беседу по conversationId. Фронтенд (веб, мобильное приложение) 
и возможные клиенты вроде Telegram Mini App или других обвязок обращаются к одному API и к одной истории. 
Любой новый клиент после входа видит ту же историю - она хранится на сервере.
