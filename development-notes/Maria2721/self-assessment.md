## 2. Описание моей работы

В ходе работы над проектом была разработана платформа для подготовки к собеседованиям, где я смогла реализовать авторизацию пользователей, поработала с refresh токеном и разобралась, как его фоново обновлять по истечении срока, чтобы пользователя мог оставаться в системе. Также в процессе реализации этой задачи я использовала библиотеку `react-hook-form`, которая серьезно упростила мне работу с формами.

Для всех API запросов я использовала toast уведомления, вызовы которых вынесла в отдельные переиспользуемые функции для всего проекта.

У меня получилось сделать чат с AI асситстентом, где нужно было красиво отобразить приходящую md разметку, в этом мне отлично помогла библиотека `react-markdown`. На фронте чат представлял из себя только get и post запросы, поэтому задача оказалась несложной, вся более трудоемкая работа была на бэке.

В проекте я активно работала с API запросами: мной был сделан блок с отдельными темами из базы знаний, блок теоретических вопросов в виде теста с проверкой выбранных вариантов ответа и блок с практическими задачами.

## 3. 2 личных Feature Component

### 3.1. Registration/Login Forms

Работа с формами для регистрации и входа в приложение, синхронизация состояния входа с refresh токеном.

### 3.2. Theoretical question

Блок, где вопрос с вариантами ответов приходит с бэка, есть возможность выбрать и отправить свой ответ в каждом вопросе, все get/post запросы имеют обратную связь с пользователем через toast уведомления.
