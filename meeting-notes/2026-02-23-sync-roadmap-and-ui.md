# Meeting Notes — Синк: roadmap по темам и UI главной

**Дата:** 2026-02-23  
**Формат:** командный созвон

---

## Краткие итоги

Детально проговорили план и логику приложения. **Habib** предложил концепцию главной страницы: дорожная карта 
(roadmap) по темам с переходами к заданиям внутри каждой темы. Команда приняла эту идею как основу для навигации по контенту. 
Договорились технически реализовать карту через **React Flow** и дополнить её боковым списком тем для быстрого доступа 
без поиска по графу. Базовая настройка фронтенда (**Base project setup**) завершена и влита в ветку разработки; 
дальнейшие задачи ведём от неё отдельными ветками.
