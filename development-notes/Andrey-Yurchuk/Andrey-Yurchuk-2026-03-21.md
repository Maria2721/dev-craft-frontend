## 2026-03-21

**Что сделал:** продолжил реализацию knowledge-блока на бэкенде: добавил новые эндпоинты, прогнал проверку в docker 
и подготовил артефакты для фронтенда.

**Какие новые (три) эндроинта были добавлены:**
- Реализован эндроинт вопросов темы GET /knowledge/topics/:topicId/questions: выдаёт структурированный ответ для фронта
(topic, questions, codeSnippet, options, correctOptionIds), с корректным 404 Topic not found для несуществующей темы.
- Реализован эндроинт отправки ответов POST /knowledge/topics/:topicId/questions/attempts (под JWT): сохранение попыток
пользователя, проверка single/multiple choice, возврат результата по отправке и агрегированного прогресса по теме.
- Реализован эндроинт GET /knowledge/topics/:topicId/code-tasks для секции практических задач: возвращает topic + отсортированный
список codeTasks (id, title, description, taskType, order).
- Подготовил для команды markdown-артефакты с вариантами ответа данных по трем описанным эндпоинтам в комментарии к задачам.
