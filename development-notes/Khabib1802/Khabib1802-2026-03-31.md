# Дата: 2026-03-31

Наконец-то начал делать `Knowledge Map`. На данный момент заменил простой список тем на интерактивную карту с помощью библиотеки React Flow.

Интересно работать с библиотеками, по началу правда ничего не понятно. А спустя время все также не понятно. Часто проблема не в коде, а в том, что я не до конца понимаю внутренние механики библиотеки. Основная проблема возникла с панорамированием карты: при первом скролле карта сдвигалась немного вправо. Долго разбирался с чем это связано: логировал координаты, читал документацию. В итоге оказалось, что причина была в `translateExtent`. Он нужен для ограничения движения карты, иначе можно бесконечно двигать карту в опреленном направлении. Я задавал ограничение и по горизонтали, и по вертикали, но для моего сценария нужно было ограничивать только по вертикали. После этого карта начала вести себя так как нужно.

Ещё одна сложность - организация кода. В какой-то момент код страницы MapPage стал слишком большим. Я вынес логику построения графа в отдельный файл `mapFlow.ts`, думаю в будущем сделаю отдельный хук.

По итогу:

- Написал функции `createNodes` и `createEdges` для преобразования данных из API в формат, понятный React Flow
- Реализовал чередование узлов (слева/справа) и анимированные линий между узлами
- С помощью встроенных аттрибутов `ReactFlow` настроил поведение карты(зум, перетаскивание и т.д.)
- Добавил обработку клика по узлу - переход на конкретную тему

Также добавил специальный роут `TopicProtectedRoute`. В отличие от обычного `ProtectedRoute`, он не просто проверяет авторизацию, а даёт неавторизованным пользователям доступ только к первой теме. Это нужно для демонстрации контента для неавторизированных пользователей. Для дальнейшего изучения требуется регистрация.

Также доработал `TopicPage` - теперь `topicId` может загружаться не только из `location.state`, но и из URL. До этого нельзя было перейти на страницу темы по прямой ссылке.
